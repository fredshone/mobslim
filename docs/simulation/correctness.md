## Reproducing

The scenario is a short one-way road with a side road joining it, a
bottleneck just after the junction, and a bus line with three stops. It is
generated by `showcase/corridor.py` and written as MATSim XML to
`showcase/scenarios/corridor/<variant>/`. Both variants have the same
network, the same two buses and the same 19 bus passengers. The congested
variant has 77 cars leaving home within 4 minutes. The free-flow variant has
20 cars spread over 8 minutes.

For each variant, `python -m showcase correctness`:

1. runs **Java MATSim 2025.0** (QSim, then Hermes) on the scenario. MATSim
   routes the plans: car routes and bus connections.
2. runs **MATSim's DSim**, its new parallel mobsim, on the same config. It
   is not in a MATSim release yet, so it comes from the weekly build
   `2027.0-2026w45`, set to the QSim's traffic model (FIFO links, queue
   dynamics, the same stuck time).
3. runs **every MobSlim mobsim on MATSim's routed plans**, so all eight
   simulations play out exactly the same trips. The MobSlim mobsims use
   MATSim's clock: whole seconds, link times rounded down, and a one-second
   step at each junction (see
   [choosing the clock](design-detail.md#choosing-the-clock)).
4. reads every simulation's MATSim-format `events` XML with **the same
   parser**, and writes the animation data to
   `docs/_static/showcase/corridor-data.js`. Vehicle positions come from
   link entry and exit times alone: a vehicle drives at the link's speed
   limit, then waits at the end of the link, behind the vehicles in front,
   until the moment it left.

It also prints a summary per variant: every car's arrival time compared
with MATSim QSim, bus arrival times at the stops, and which bus each
passenger caught.

Running it needs Java 21+, Maven and a `matsim-libs` checkout, as for the
verification suite (see `verification/README.md`). It takes about a minute.

```bash
uv run python -m showcase correctness   # both variants: MATSim, MobSlim, animation data
uv run --group docs sphinx-build docs docs/_build
```

The [verification suite](https://github.com/fredshone/mobslim/blob/main/verification/README.md)
runs the same comparison at larger scale on MATSim's own example scenarios,
and also checks scoring and the whole replanning loop.
